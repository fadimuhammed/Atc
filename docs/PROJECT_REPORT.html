Smart Air Traffic Control Priority Landing Simulator

B.Tech CSE (Cyber Security), Batch 2025-29 | Semester III

Course Codes: 24CCT201 Data Structures & Algorithms, 24CCT203 OOP Java

Abstract

This project presents a Smart Air Traffic Control (ATC) Priority Landing Simulator implemented in Java, integrating principles from Data Structures and Algorithms (DSA) and Object-Oriented Programming (OOP). The system manages landing requests from commercial, cargo, and emergency aircraft using custom data structures implemented from scratch without the Java Collections Framework.

1. Introduction

Problem Statement

Managing aircraft landing sequences at busy airports requires efficient prioritization considering fuel levels, emergency status, wait time, and aircraft type.

Objectives

  • Design class hierarchy using OOP concepts with proper encapsulation
  • Implement at least four non-trivial data structures from scratch
  • Apply sorting and searching algorithms with complexity analysis
  • Demonstrate exception handling and file persistence

3. Algorithms

Merge Sort

Recursive divide-and-conquer sorting. Time: O(n log n), Space: O(n)

// Pseudocode
function mergeSort(array)
    if length <= 1 return array
    mid = length/2
    left = mergeSort(array[0:mid])
    right = mergeSort(array[mid:])
    return merge(left, right)

Iterative search on sorted array. Time: O(log n)
