SMART AIR TRAFFIC CONTROL PRIORITY LANDING SIMULATOR
B.Tech CSE (Cyber Security), Batch 2025-29 | Semester III
Course Codes: 24CCT201 Data Structures & Algorithms, 24CCT203 OOP Java

================================================================================
ABSTRACT
================================================================================

This project presents a Smart Air Traffic Control (ATC) Priority Landing 
Simulator implemented in Java, integrating principles from Data Structures and 
Algorithms (DSA) and Object-Oriented Programming (OOP). The system manages 
landing requests from commercial, cargo, and emergency aircraft using custom 
data structures implemented from scratch without the Java Collections Framework.

================================================================================
1. INTRODUCTION
================================================================================

PROBLEM STATEMENT:
Managing aircraft landing sequences requires efficient prioritization considering
fuel levels, emergency status, wait time, and aircraft type.

OBJECTIVES:
- Design class hierarchy using OOP concepts
- Implement 4+ non-trivial data structures from scratch
- Apply sorting and searching algorithms with complexity analysis
- Demonstrate exception handling and file persistence

2. DATA STRUCTURES IMPLEMENTED
================================================================================

2.1 ARRAY-BASED PRIORITY QUEUE (Heap)
Operation          Time Complexity    Space
Enqueue            O(log n)           O(n)
Dequeue            O(log n)           -
Peek               O(1)               -

2.2 CIRCULAR QUEUE
Operation          Complexity
Enqueue/Dequeue    O(1)

2.3 HASH TABLE WITH CHAINING
Operation          Average    Worst
Put/Get/Remove     O(1)       O(n)

2.4 SORTED ARRAY REGISTRY
Operation          Complexity
Binary Search      O(log n)
Insert             O(n)

2.5 STACK (Undo Operations)
Operation: Push/Pop/Peek - O(1)

================================================================================
3. ALGORITHMS
================================================================================

MERGE SORT:
Time: O(n log n) best/average/worst
Space: O(n) auxiliary
Stable sort with guaranteed performance

BINARY SEARCH:
Time: O(log n)
Iterative search on sorted array

HASH LOOKUP:
Average: O(1)
Worst: O(n) with collisions

================================================================================
5. PRIORITY SCORING ALGORITHM
================================================================================

Priority Score = w_emergency × emergencyFlag + w_fuel × (100 - fuelLevel) 
                 + w_wait × waitMinutes

WEIGHTS:
Type        Emergency   Fuel    Wait
Commercial  1000        10      1
Cargo       800         15      2
Emergency   10000       0       0
